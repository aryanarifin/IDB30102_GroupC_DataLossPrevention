
# Research Papers Directory

This directory is designated for storing all primary research literature, academic journals, and conference papers relevant to Data Loss Prevention (DLP), User and Entity Behavior Analytics (UEBA), and insider threat detection mechanisms.

## Folder Objectives
- Archive foundational and contemporary literature collected for the research project.
- Provide direct access to full-text PDF documents, DOI links, and publication metadata.
- Serve as the raw evidence base for conducting the systematic literature review and gap analysis.
