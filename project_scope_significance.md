# Project Scope & Significance

## Scope of the Project
- **In-Scope:**
  - Design of a behavioral data loss prevention monitoring framework.
  - Integration of synthetic UEBA logs and mock data exfiltration scenarios.
  - Evaluation of detection precision, recall, and operational alert overhead.
- **Out-of-Scope:**
  - Hardware-level physical security integration.
  - Proprietary vendor code modifications.

## Significance of the Study
This study contributes to standardizing DLP research by bridging behavioral threat analysis with context-aware classification, helping organizations reduce data leak risks while minimizing false-positive alert burden.
