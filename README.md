## Research Title
Enhancing Enterprise Data Protection: A Multi-Layered Data Loss Prevention (DLP) Framework Combining User Behavior Analytics and Automated Data Classification

## Research Problems
1. Traditional static DLP rules fail to identify gradual insider threats and abuse of legitimate access rights.
2. High false-positive rates in monitoring unstructured data across cloud and endpoint environments cause security alert fatigue.

## Research Aim & Objectives
**Aim:** To design and evaluate an adaptive, multi-layered DLP framework for proactive data leakage prevention.
- **RO1:** Analyze existing DLP techniques and insider-threat detection methods to isolate current research gaps.
- **RO2:** Design and develop a hybrid framework architecture integrating UEBA and automated context-aware data classification.
- **RO3:** Evaluate the proposed solution's accuracy, recall, and false-positive mitigation using test datasets.

## Brief Description of Proposed Solution
A multi-layered DLP framework that fuses endpoint process monitoring with real-time user risk scoring and dynamic document classification. It prevents unauthorized exfiltration attempts before execution while minimizing false alarms for authorized data transfers.
