# Datasets and Sample Input Files

This directory contains the experimental datasets, synthetic user activity logs, and sample documents utilized to evaluate the performance of the DLP framework.

## Repository Contents
- Structured and unstructured test files containing mock sensitive data (PII, financial records, confidential text).
- Simulated endpoint logs and enterprise user behavior logs for UEBA evaluation.
- Preprocessed input data files used for model validation and testing.
